# Analysis 1A - Calculus 1A
Lecturer: Assoc. Prof. Dr. Vo Si Trong Long

Teaching Assistant (for exercise hours): Nguyen Thanh Loc
## About the content: 

This course is regarded as one of the hardest courses in this Semester, mainly because this course teaches how to view Mathematics abstractly, with way fewer numbers and way more letters for us to comprehend. Personally, I enjoyed this course very much cause it really helps me to view Math in a (frankly) different way, and actually know how math was built from the very first steps, from Peano Axioms to Set theory. I really enjoyed it!
